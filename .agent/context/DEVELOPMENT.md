# Разработка — порядок и состояние

Импорт материалов завершён, реализация не начата. Полный [план](../../docs/development/roadmap.md), [контрольные точки](../../docs/development/milestones.md), [workflow](../../docs/development/workflow.md). Это не MVP: все этапы 0–11 и все домены сохранены.

Внутри этапа: миграции/DB-тесты → API/curl → бот → UI. Спайк 0 должен закрыть relay/Foundry, headless, PF2e, WebDAV и Codex до этапа 2. Основа (этап 1) может готовиться независимо от тестового мира, но не объявляется готовой после одного SQL-прогона.

TASK-001 закрывает именно контекст/доступные проверки, не Go-каркас. TASK-002 — этап 0, TASK-003 — этап 1; далее TASK-004…TASK-013 соответствуют этапам 2…11. Продуктовые требования FM-REQ-001…012 содержат полные критерии соответствующих этапов; FM-REQ-013 — сохранность/доступность артефактов. У остальных статус proposed: вопросы владельца не решены автоматически.

Go/TypeScript toolchain, Compose, API и миграции пока не созданы. Точные выполненные проверки — [verification](../../docs/verification.md). Текущие задачи и blockers — только в state/current.yaml и единственном state/HANDOFF.md. Все вопросы: [полный список](../../docs/development/open-questions.md); отсутствующее ТЗ: [source-gaps](../../docs/development/source-gaps.md).
