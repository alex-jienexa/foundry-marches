# 8. Экспедиции

## Statement

Реализовать весь состав этапа без сокращения: маршруты, состав, припасы, дневные переходы, посещённые гексы

## Rationale and source

Полный [план этапов](../../docs/development/roadmap.md); [профильный полный раздел](../../docs/architecture/expeditions.md). Ссылки на сценарии исходного ТЗ сохранены, но само ТЗ отсутствует — не достраивать его по предположениям. [Открытые вопросы](../../docs/development/open-questions.md) решает project-owner перед зависимой реализацией.

## Acceptance criteria

- [ ] Проверки: предпросмотр и подтверждение дня; нехватка припасов не списывает в минус и создаёт событие; персонаж не может быть в двух активных экспедициях
- [ ] Итог: экспедиция от выхода до возвращения, с хроникой и наградами
- [ ] Для всех операций выполняются серверные permissions/CanSee, журналы/инварианты и безопасность из полных разделов.
- [ ] DB → API/curl → bot → UI, если применимо этапу; источники истины, контекст и тесты обновлены.
