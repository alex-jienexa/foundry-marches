# 9. Фракции

## Statement

Реализовать весь состав этапа без сокращения: репутация, ступени, отношения, территории, политические события

## Rationale and source

Полный [план этапов](../../docs/development/roadmap.md); [профильный полный раздел](../../docs/architecture/factions.md). Ссылки на сценарии исходного ТЗ сохранены, но само ТЗ отсутствует — не достраивать его по предположениям. [Открытые вопросы](../../docs/development/open-questions.md) решает project-owner перед зависимой реализацией.

## Acceptance criteria

- [ ] Проверки: значение репутации равно сумме журнала; обратная запись; применение события пишет историю; игрок не видит скрытое
- [ ] Итог: репутация открывает товар в магазине, слой территорий на карте
- [ ] Для всех операций выполняются серверные permissions/CanSee, журналы/инварианты и безопасность из полных разделов.
- [ ] DB → API/curl → bot → UI, если применимо этапу; источники истины, контекст и тесты обновлены.
